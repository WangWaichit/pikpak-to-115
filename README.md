# PikPak ↔ 115 网盘双向同步工具

在小内存 VPS 上跑的命令行工具，把 PikPak 和 115 网盘的文件夹互相同步。
流式传输、按文件名+大小智能去重、同名新文件自动覆盖旧文件。

---

## 一、安装

```bash
git clone https://github.com/WangWaichit/pikpak-to-115.git
cd pikpak-to-115
./run.sh install
```

要求：Python 3.8+。常驻内存 ~40MB，传输时按 1MB 块流式处理，不占大内存。

---

## 二、准备两个凭证

### 1. PikPak 长期令牌

登录 PikPak 网页版 → 头像 → 设置 → 开发者 / API → 生成 Long-term Access Token（`eyJ...` 开头的一串）。

### 2. 115 cookies

浏览器登录 https://115.com → F12 → Application → Cookies → 找到 `UID`、`CID`、`SEID`、`KID`，拼成一行：

```
UID=123456; CID=xxx; SEID=xxx; KID=xxx
```

## 三、启动

```bash
./run.sh
```

第一次会问你两个凭证，粘进去回车即可（保存在本地 `config.json`，不会上传）。

之后进入主菜单：

```
===== PikPak <-> 115 =====
  1. 列出 115 目录
  2. 列出 PikPak 目录

  4. 拷贝 PikPak 目录文件到 115 目录

  7. 测试 115 cookies 连通性
  8. 测试 PikPak token 连通性
  9. 测试网盘是否连接（双侧）
  10. 退出
===========================
请选择 [1-10]:
```

## 四、怎么传文件（最常用）

以菜单 `4`（PikPak → 115）为例，菜单 `3` 反向同理。

### 步骤

1. **选 4**，开始选择传输
2. **选源**：进入 PikPak 目录树
   - 数字 `1/2/3...` 进对应子目录
   - `..` 回上一层
   - `.` 或回车 = 选中当前目录作为源
   - `0` 取消，回主菜单
3. **选目标父目录**：进入 115 目录树（同上操作）
4. **起新文件夹名**，会问你：
   ```
   源目录名: 「电影」
   目标父目录: /备份
     [1] 直接复制过去：在 /备份 下建「电影」（保持原名）
     [2] 新建自定义文件夹：你输入一个新名字，把文件传进去
     [0] 取消
   ```
   - 选 `1`：直接用源目录名
   - 选 `2`：自己起个新名（比如 `movie`）
5. 确认 `Y` 后，**后台线程开始传**，立刻回到主菜单
6. 选 `5` 看实时进度

### 例子

源 PikPak：
```
/离线下载/电影/
├── 港片/
│   ├── A计划.mkv
│   └── 警察故事.mkv
└── 好莱坞/盗梦空间.mp4
```

选源 = `/离线下载/电影`，目标父目录 = `/备份`，新名 = `movie`：

115 端结果：
```
/备份/movie/
├── 港片/
│   ├── A计划.mkv
│   └── 警察故事.mkv
└── 好莱坞/盗梦空间.mp4
```

子目录层级和文件名**原样保留**，只是根目录从"电影"换成了"movie"。

## 五、去重规则

| 情况 | 行为 |
|---|---|
| 目标里没有同名文件 | 正常传 |
| 同名 + 新文件 ≤ 旧文件 | 跳过 |
| 同名 + 新文件 > 旧文件 | **删旧传新**（旧文件进回收站，可恢复） |

递归到所有子目录。

## 六、后台运行（关 SSH 不断）

传大文件时不想一直挂着 SSH，用 daemon 模式：

```bash
# 1. 后台静默启动
./run.sh daemon

# 2. 看到菜单后正常选 3 或 4，选完源/目标/新名，确认 Y
# 3. 任务开始后，直接关 SSH 窗口，传输继续
```

下次连回来：

```bash
# 看进度（任何时候都能跑）
./run.sh status

# 停止后台任务
./run.sh stop
```

`status` 输出示例：

```
----- 任务进度 -----
  状态: 传输中
  方向: pikpak->115
  源:   /离线下载/电影
  目标: /备份/movie
  文件: 12/30 (40.0%)
  当前: 盗梦空间.mp4
  已运行: 352 秒
  上次更新: 14:23:05
--------------------
```

## 九、常见问题

**Q: 同时能跑几个任务？**
A: 一个。已有任务在跑时选 3/4 会提示。

**Q: 传一半中断了怎么办？**
A: 重新跑同一条任务即可。`.part` 文件会续传，已传完的文件会按去重规则跳过。

**Q: 传错了想撤回？**
A: 同名覆盖时旧文件是移到回收站，不是永久删除，去网盘回收站恢复即可。

**Q: 115→PikPak（菜单 3）报错？**
A: 这个方向的 PikPak 上传是新写的，遇到报错把 `sync.log` 最后几十行发出来。
